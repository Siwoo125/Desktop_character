# DesktopCharacter · 바탕화면 친구

강아지, 보노보노, 직접 만든 캐릭터가 바탕화면에서 걷고 뛰는 데스크톱 펫입니다. 여러 종류와 같은 캐릭터 여러 마리를 함께 띄울 수 있습니다. macOS는 Swift/AppKit, Windows는 Python/PySide6로 구현했습니다.

## 다운로드 · 실행

[**v1.0.0 다운로드**](https://github.com/Siwoo125/Desktop_character/releases/tag/v1.0.0)

| 운영체제 | 받을 파일 | 실행 방법 |
| --- | --- | --- |
| macOS 13 이상 · Apple Silicon / Intel | `DesktopCharacter-1.0.0-macOS-Universal.zip` | 압축 해제 → `바탕화면 강아지.app`을 응용 프로그램 폴더로 옮겨 실행 |
| Windows 10/11 · x64 | `DesktopCharacter-1.0.0-Windows-x64.zip` | **전체 압축 해제** → `DesktopCharacter.exe` 실행 |

배포 ZIP은 Swift·Python을 따로 설치할 필요가 없습니다. Windows는 EXE 옆의 `_internal`, `licenses` 폴더도 함께 보관하세요. macOS 앱은 임시 서명(ad-hoc)만 했으며 Developer ID 서명·공증을 하지 않았습니다. Windows EXE도 배포자 인증서 서명이 없습니다. macOS가 실행을 차단하면 출처를 확인한 뒤 [Apple의 앱별 실행 허용 안내](https://support.apple.com/ko-kr/102445)를 참고하세요.

첫 실행에는 **강아지 한 마리**가 나타납니다. 다음 실행부터는 저장된 캐릭터 구성을 복원하고, 저장된 수가 0마리면 강아지 한 마리를 띄웁니다. 메뉴는 macOS 메뉴 막대 또는 Windows 트레이(숨겨진 아이콘 `∧`)에 있습니다.

## 할 수 있는 것

- 각각 다른 시간표로 걷기·달리기·휴식, 커서 바라보기
- 중력과 실제 창의 위·아래 테두리 착지, 낮은 창부터 차례로 오르기
- 화면 왼쪽·오른쪽 끝을 넘어 반대편으로 나오기
- 약 1분마다 가까운 곳에 멈춘 커서 잡기·구르기 시도
- 드래그로 이동, 우클릭으로 크기 변경·동작 예시·일시정지
- 직접 만든 스프라이트로 캐릭터 등록, 여러 종류·중복 캐릭터 함께 띄우기

캐릭터를 우클릭하거나 공용 메뉴에서 **캐릭터 관리 (+ / −)…**를 여세요.

| 버튼·메뉴 | 동작 |
| --- | --- |
| **+** | 해당 캐릭터 한 마리 추가. 같은 종류도 여러 마리 가능 |
| **−** | 화면에서 한 마리 내리기. 보관함은 유지 |
| **삭제** | 직접 만든 캐릭터를 보관함에서 삭제하고 그 종류를 모두 내리기. 강아지·보노보노는 삭제 불가 |
| **동작 예시** | 대기, 걷기, 뛰기, 점프, 하강, 커서 잡기 등을 직접 실행 |
| **모두 종료** | 앱 전체 종료 |

0마리가 되어도 공용 메뉴는 남습니다. 생성·관리 화면을 사용하는 동안 캐릭터들은 잠시 멈춥니다. 자동 커서 잡기는 커서가 가깝고 잠시 멈춰 있을 때만 시도합니다. 잡힌 뒤 움직이거나 클릭하면 놓습니다. 여러 마리 중 한 마리만 커서를 잡습니다.

macOS는 실제 포인터를 원래 위치에서 잠시 숨기고 손에 커서를 그립니다. Windows는 실제 포인터가 손을 따라 이동하며, 사용자가 움직이지 않았으면 동작 종료 후 원래 위치로 돌려놓습니다.

## 키보드 조종

캐릭터 우클릭 → **키보드 조종 켜기**를 선택하세요. 조종하는 캐릭터에 포커스가 있을 때 작동합니다.

| 키 | 동작 |
| --- | --- |
| A / D | 왼쪽 / 오른쪽 이동 |
| W / Space | 점프 |
| S | 현재 발판에서 내려가기 |
| Shift + A/D | 달리기 |
| Esc | 자동 모드로 복귀 |

## 내 캐릭터 만들기

1. 메뉴의 **캐릭터 생성…**을 엽니다. 강아지·보노보노 예시를 보고 **예시 세트 저장…**으로 제작 참고 파일을 저장할 수 있습니다. 예시 이미지의 권리는 [에셋 안내](ASSET_LICENSES.md)를 따릅니다.
2. 아래 구성에 맞는 **투명 PNG**를 만들고 동작별 **이미지 선택…**으로 등록합니다. 미리보기 재생으로 순서를 확인하세요.
3. 이름을 입력하거나 **이름 추천**을 누릅니다. **저장하고 사용**을 누르면 기존 캐릭터들을 유지하며 새 캐릭터 한 마리를 추가합니다.

| 이미지 | 프레임 구성 |
| --- | --- |
| 정지 | 1장 |
| 커서 바라보기 | 가로 3칸: 왼쪽 위 → 정면 위 → 오른쪽 위 |
| 오른쪽 걷기, 달리기, 대기, 점프, 커서 잡기, 구르기 | 각각 **4칸 × 2줄, 8프레임** |
| 왼쪽 걷기 | 선택. 생략하면 오른쪽 걷기를 좌우 반전 |

**필수 8종 + 선택 1종**입니다. 8프레임은 윗줄 왼쪽 → 오른쪽, 아랫줄 왼쪽 → 오른쪽 순서입니다. 예를 들어 2048×1024 PNG에 512×512 칸 8개를 배치하세요. 빈 칸 없이 각 자세를 칸 안에 넣어야 합니다. 한 칸 최소 8픽셀, 전체 한 변 최대 8192픽셀·총 16,777,216화소입니다.

점프는 윗줄 도약·아랫줄 하강(각 줄 준비 → 공중 → 착지 직전 → 착지) 또는 연속 8자세 중 선택할 수 있습니다. **커서 잡기·구르기에는 커서를 그리지 마세요.** 미리보기에서 프레임을 고르고 손 위치를 클릭해 커서 접점을 맞춥니다. 점프 5~8번, 구르기는 모든 프레임에 적용됩니다.

## 저장 위치와 개인정보

| 운영체제 | 사용자 캐릭터 | 설정 |
| --- | --- | --- |
| macOS | `~/Library/Application Support/DesktopFriends/characters/` | UserDefaults: `local.desktopdog.idle` |
| Windows | `%LOCALAPPDATA%\DesktopFriends\characters\` | `%LOCALAPPDATA%\DesktopFriends\settings.json` |

사용자 이미지는 보관함에 복사하며 원본을 수정하지 않습니다. 삭제한 캐릭터는 보관함의 `.trash/`로 옮깁니다. 캐릭터 폴더의 PNG와 `character.json`은 두 운영체제에서 같은 형식입니다. Windows 오류 로그는 `%LOCALAPPDATA%\DesktopFriends\desktop-pet.log`에 있습니다.

창 인식은 위치·크기·가림 관계를 사용하며 창 제목이나 스크린샷을 저장하지 않습니다. 실행 앱에는 분석·광고·업로드 기능이 없습니다. 소스 실행을 위한 Windows 최초 설치는 패키지 다운로드에 인터넷을 사용합니다.

## 소스에서 실행

macOS: Xcode Command Line Tools가 필요합니다.

```sh
./scripts/build.sh
open "build/바탕화면 강아지.app"
```

또는 `실행.command`를 더블클릭하세요. Windows: Python 3.13 64비트를 설치하고 `Start-Windows.cmd`를 실행하세요. 필요한 패키지는 프로젝트 내부 가상환경에 설치합니다. 소스를 수정한 뒤에는 기존 앱을 **모두 종료**하고 다시 실행하세요.

구조·검사 방법은 [개발 안내](docs/DEVELOPMENT.md), Windows 상세 조작은 [Windows 안내](windows/README.md), 배포 파일을 다시 만드는 방법은 [릴리스 안내](docs/RELEASING.md)에 있습니다. `.github/workflows/release.yml`은 두 운영체제에서 빌드·자동 검사를 수행합니다.

아직 먹이·성장 기능은 없습니다. macOS의 백그라운드 커서 숨김 일부는 비공개 API를 사용하므로 OS 버전의 영향을 받을 수 있고, App Store 배포를 대상으로 하지 않습니다. 자동 검사는 실제 화면에서의 모든 창 조합·DPI·입력 동작을 보장하지 않습니다.
