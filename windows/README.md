# 바탕화면 친구 — Windows 실행

강아지·보노보노·내 캐릭터를 여러 마리 띄울 수 있는 Windows용 실행부입니다. 같은 캐릭터도 여러 마리 추가합니다. 기존 macOS Swift 앱은 `Sources/`에 유지하고, Windows 창·트레이·입력 처리는 Python + PySide6와 공개 Win32 API로 구현했습니다. 이미지 원본은 두 버전에서 같은 `img/`를 사용합니다.

## 바로 실행

[GitHub Releases](https://github.com/Siwoo125/Desktop_character/releases/tag/v1.1.0)에서 **`DesktopCharacter-1.1.0-Windows-x64-Setup.exe`**를 받으세요. 설치 완료 화면의 실행 체크를 켠 채 **마침**을 누르면 바로 실행합니다. 관리자 권한 없이 `%LOCALAPPDATA%\Programs\DesktopCharacter`에 설치하며 시작 메뉴에도 추가합니다. 다운로드만으로 실행되거나 로그인 시 자동 실행되지는 않습니다. 삭제는 Windows 설정의 앱 제거를 사용하며 사용자 캐릭터·설정·API 키는 유지합니다.

설치 없는 `DesktopCharacter-1.1.0-Windows-x64.zip`도 제공합니다. Windows 10/11 x64에서 전체 압축 해제 후 **`DesktopCharacter.exe`**를 실행합니다. Python 설치는 필요 없습니다. EXE 옆 `_internal`, `licenses` 폴더도 함께 유지하세요. 배포자 인증서 서명은 하지 않았습니다.

소스로 실행하려면 Python 3.13 x64를 설치한 뒤 저장소의 `Start-Windows.cmd`를 실행합니다. Python 3.11~3.14도 지원합니다. 첫 실행은 필요한 패키지를 프로젝트의 `.venv-windows`에 설치하므로 인터넷이 필요합니다. 시스템 Python 패키지나 관리자 권한 설정은 바꾸지 않습니다.

작업 표시줄의 숨겨진 아이콘 **∧**에서 트레이 아이콘을 우클릭하세요. 트레이 아이콘은 하나이며 두 번 클릭하면 캐릭터 관리 화면을 엽니다. 0마리여도 아이콘은 유지됩니다.

## 메뉴와 조작

- **캐릭터 관리 (+ / −)…** → 종류별 **+**로 한 마리 추가, **−**로 한 마리 내리기. 같은 캐릭터도 여러 마리 띄울 수 있습니다.
- 관리 화면의 **삭제** → 내 캐릭터를 보관함에서 삭제하고 그 종류의 복사본을 모두 내립니다. 확인 창을 표시하며 **강아지·보노보노는 삭제 불가**입니다.
- 캐릭터 우클릭 → **+ 같은 캐릭터 추가 / − 이 캐릭터 없애기** 또는 **캐릭터 선택**으로 해당 한 마리 교체
- **캐릭터 생성…** → 내 PNG로 새 캐릭터 등록
- **동작 예시** → 대기 동작, 커서 잡기, 걷기, 뛰기, 위로 점프, 아래로 내려가기, 방향 바꾸기
- **키보드 조종 켜기** → A/D 이동, W 또는 스페이스 점프, S 하강, Shift+A/D 달리기, Esc 자동 모드 복귀
- **크기 배율** → 0.5 / 0.75 / 1 / 1.25 / 1.5 / 2 / 3배
- 각 캐릭터를 따로 드래그·일시정지·숨기기·크기 변경. 앱 전체를 끝낼 때는 **모두 종료**

트레이에는 현재 캐릭터들의 이름별 서브메뉴도 있습니다. 각 복사본은 위치·크기·물리·동작을 따로 갖고, 종류와 복사본 수는 재실행에도 복원됩니다. −는 보관함을 지우지 않습니다. 모두 내려도 관리 화면의 +로 다시 띄울 수 있습니다.

첫 실행 또는 저장된 캐릭터가 0마리인 경우 기본 강아지 한 마리를 자동으로 띄웁니다. 실행 중에는 −로 모두 내릴 수 있으며, 다음 실행에서는 다시 강아지 한 마리가 나타납니다. 저장된 캐릭터가 있으면 해당 구성을 그대로 복원합니다.

자동 행동은 캐릭터별로 다른 시간표를 사용합니다. 시작·메뉴 재개 후 약 0.8~4.5초의 개별 지연을 두고, 1.5~5.5초 이동한 뒤 1.2~6초 쉽니다. 30% 확률로 이동 없이 더 쉬기도 합니다. 진행 중인 순차 등반은 이어가고, 키보드 조종·동작 예시는 직접 입력에 따라 동작합니다.

키보드 조종은 캐릭터에 포커스가 있을 때만 작동합니다. 다른 앱으로 옮기면 눌린 키를 정리해 정지하고, 캐릭터를 클릭하면 다시 조종합니다. 자동 모드는 다른 앱의 포커스를 가져오지 않습니다.

## 내 캐릭터 만들기

**캐릭터 생성…** 화면에서 강아지·보노보노의 동작별 예시를 보고 PNG를 선택하세요. **예시 세트 저장…**은 동작별 PNG, 참고 이미지 2장과 만드는 방법을 새 폴더에 복사합니다. 강아지는 전용 왼쪽 걷기 PNG가 없어 자동 반전을 사용합니다. **미리보기 · 재생**으로 업로드한 프레임을 확인하고, 이름을 입력하거나 **이름 추천**을 누른 뒤 **저장하고 사용**을 선택하면 새 캐릭터 한 마리를 추가합니다. 기존 캐릭터는 유지합니다.

- 정지 자세는 1장, 시선은 가로 3칸(왼쪽 위 → 정면 위 → 오른쪽 위)입니다.
- 걷기·달리기·대기·점프·커서 잡기·구르기는 각각 **4칸 × 2줄의 8프레임**입니다. 윗줄 왼쪽부터, 다음 아랫줄 왼쪽부터 재생합니다. 예: 2048 × 1024 PNG.
- 필수는 8종입니다. 왼쪽 걷기는 선택이며 생략하면 오른쪽 걷기를 반전합니다.
- 투명 배경을 사용하고, 각 자세는 같은 크기로 나눈 칸 안에 전부 들어가야 합니다. 빈 칸은 허용하지 않습니다. 각 칸 최소 8픽셀, 전체 한 변 8192픽셀·16,777,216화소 이하입니다.
- 점프는 윗줄 도약·아랫줄 하강(각 줄 준비 → 공중 → 착지 직전 → 착지) 또는 연속 8자세를 고르세요.
- 커서 잡기·구르기는 커서 없이 그립니다. 미리보기에서 프레임을 고르고 손을 클릭해 청록색 접점을 조절하세요. 점프 5~8번, 구르기는 전체에 적용됩니다.

이미지는 PC의 사용자 보관함에 복사하며 원본을 수정하지 않습니다. 저장 후 **캐릭터 선택** 메뉴에 추가되고 다음 실행에도 복원됩니다. 보관함은 `%LOCALAPPDATA%\DesktopFriends\characters\`입니다. 캐릭터별 폴더의 PNG와 `character.json`은 macOS와 같은 형식입니다.

중력, 작업 표시줄 위의 지면, 실제 창의 위·아래 테두리 착지, 창 이동·닫힘, 앞 창에 가려진 발판 제외, 낮은 창부터 차례로 오르기, 현재 모니터의 좌우 끝 연결을 적용합니다. 다른 모니터로 옮길 때는 캐릭터를 드래그하세요. 모니터별 DPI 비율과 음수 화면 좌표를 별도로 변환합니다.

## AI 모션 생성

기본 정지 PNG만 선택하고 **API 추가 · 검증…**에서 개인 키를 등록할 수 있습니다. **검증 → 추가** 후 이미지 API를 골라 **전체 모션 만들기**를 누르세요. 동작별 재생성 버튼과 생성 중단 버튼도 있습니다. OpenAI·Gemini는 시트 생성, Claude는 선택 설명 보조용입니다. API 키는 Windows 자격 증명 관리자에 저장하며 설정 JSON에 포함하지 않습니다.

생성에는 정지 이미지와 현재 선택한 모션 예시를 함께 전송하고 개인 API 요금이 발생할 수 있습니다. [상세 안내](../docs/AI_MOTIONS.md)를 확인하세요.

## 커서 잡기

자동 모드에서 약 1분마다 근처의 멈춘 커서를 잡으려 시도합니다. 수동 시도는 **동작 예시 → 커서 잡기**를 고른 뒤 커서를 잡을 수 있는 높이에 두고 1초간 멈추면 됩니다.

Windows에서는 **실제 포인터가 캐릭터의 손을 따라 이동**합니다. 가만히 두면 잡은 채 착지하고 구르기를 두 번 재생한 뒤 원래 위치에 돌려놓습니다. 움직이거나 클릭하면 바로 놓고 사용자가 옮긴 위치를 우선합니다. 메뉴·캐릭터/배율 변경·일시정지·숨기기·드래그·잠자기·종료 시에도 동작을 정리합니다. 시스템 커서 이미지를 교체하거나 마우스를 잠그지 않습니다.

여러 마리 중 한 번에 한 마리만 커서를 잡습니다. −나 삭제로 내릴 때도 먼저 커서를 복구합니다. 메뉴·관리·생성 화면 사용 중에는 동작을 멈춥니다.

## Windows에서 검사

`windows/test.cmd`를 더블클릭하세요. 다음 결과가 콘솔에 남습니다.

- 중력·발판·창 가림·순차 등반·좌우 연결·혼합 DPI 좌표 변환
- WASD·키 해제·포커스 해제·달리기·점프
- 1분 간격 커서 시도·구르기 8프레임·사용자 이동/클릭 우선·원위치 복귀
- 두 캐릭터 이미지·배율·Qt 화면 그리기·서브메뉴·캐릭터 전환
- 캐릭터 생성 UI·예시 저장·PNG 검사·이름·독립 보관·재실행 복원·손 위치 조절
- 여러 종류·중복 복사본·독립 물리/크기·+ / − UI·0마리 재추가·목록 저장·사용자 삭제·기본 캐릭터 보호
- 실제 Windows 모니터/DPI 정보와 인식한 창·발판 개수

자동 동작 검사에서는 커서와 외부 창 API에 테스트 대역을 사용하므로 실제 포인터를 움직이지 않습니다. 마지막 진단은 창의 위치 정보만 읽으며 창 제목이나 스크린샷은 읽지 않습니다. 이후 `Start-Windows.cmd`로 실제 투명 창, 트레이, 다른 창 위 착지, 조종 포커스, 커서 잡기를 확인해 주세요. 릴리스 CI는 실제 Windows 환경에서 소스·패키징 EXE 검사와 읽기 전용 Win32 진단을 수행합니다. 실제 데스크톱의 전체 입력·다중 모니터 조합은 수동 확인이 필요합니다.

진단만 따로 실행하려면 명령 프롬프트에서 다음을 사용하세요.

```bat
Start-Windows.cmd --diagnose
Start-Windows.cmd --character bonobono
```

두 번째 명령은 기존 실행을 종료한 뒤 사용하세요. 캐릭터 선택은 다음 실행에도 저장됩니다.

## EXE 만들기와 친구에게 공유

Windows에서 **`windows/build.cmd`**를 더블클릭합니다. PyInstaller 설치 후 다음 파일을 만듭니다.

```text
dist/windows/DesktopCharacter/DesktopCharacter.exe
dist/DesktopCharacter-1.1.0-Windows-x64.zip
```

친구에게는 생성된 **ZIP 전체**를 보내세요. 압축을 푼 뒤 `DesktopCharacter.exe`를 실행하면 됩니다. 친구 PC에는 Python을 설치하지 않아도 됩니다. EXE 하나만 떼어 보내지 말고 `_internal`, `licenses`를 포함한 전체 폴더를 유지하세요. 이 스크립트는 Windows에서 실행해야 하며 macOS에서 Windows EXE를 생성하지 않습니다. 배포용 인증서 서명은 별도입니다.

빌드에 사용한 Qt/PySide6, Shiboken6 및 Pillow 라이선스 파일과 `THIRD_PARTY_NOTICES.txt`를 ZIP에 포함합니다. Qt는 개별 DLL로 배포합니다.

## 설정·오류 로그

```text
%LOCALAPPDATA%\DesktopFriends\settings.json
%LOCALAPPDATA%\DesktopFriends\desktop-pet.log
```

`settings.json`의 `instances`에 모든 복사본의 캐릭터·배율·위치를 저장합니다. 빈 목록으로 시작하면 기본 강아지 한 마리를 생성하며, 이전 단일 캐릭터 설정은 한 마리로 이전합니다. 삭제한 사용자 캐릭터 파일은 `characters\.trash\`로 옮기고 목록에서 제외합니다. 오류가 생기면 `test.cmd` 출력과 로그를 함께 전달하면 됩니다. 설정 파일이 손상되면 기본 설정으로 시작합니다. 앱을 종료한 뒤 `settings.json`을 지우면 초기화됩니다.

## 개발 구조

| 파일 | 역할 |
| --- | --- |
| `desktop_pet/physics.py` | 중력·창 발판·가림·순차 등반 |
| `desktop_pet/engine.py`, `animation.py` | 자동/수동 행동·프레임·커서 상태 |
| `desktop_pet/assets.py` | 공용 PNG 로딩·투명 여백·한글 파일명 정규화 |
| `desktop_pet/win32.py` | 창 목록·DWM 테두리·모니터·포인터·활성화 |
| `desktop_pet/app.py` | Qt 투명 창·트레이·메뉴·입력 |
| `desktop_pet/collection.py` | 여러 캐릭터·공용 트레이·+ / − 관리·삭제 보호 |
| `desktop_pet/creator.py`, `custom.py` | 캐릭터 생성 화면·PNG 검사·사용자 보관함 |
| `desktop_pet/checks.py`, `validation.py` | 플랫폼 독립 검사·Qt 검사 |

macOS에서 로직만 검사할 때는 Python 표준 라이브러리로 `python3 windows/launch.py --self-test`를 실행할 수 있습니다. Qt·이미지 검사는 별도 가상환경에 `windows/requirements.txt`를 설치한 뒤 `--validate-assets --widget-check --preview-dir .build/windows-preview`를 추가합니다.
