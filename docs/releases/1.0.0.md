DesktopCharacter 첫 공개 버전입니다. 강아지·보노보노·직접 만든 캐릭터를 여러 마리 바탕화면에 띄울 수 있습니다.

- 캐릭터별 독립적인 걷기·달리기·휴식, 창 테두리 점프·순차 등반
- 커서 바라보기·잡기·구르기, WASD/스페이스 조종
- 내 PNG로 캐릭터 생성, + / − 관리, 크기 조절과 구성 복원
- 첫 실행은 강아지 한 마리로 시작

**macOS 13 이상:** `macOS-Universal.zip`을 풀고 `바탕화면 강아지.app` 실행. Apple Silicon·Intel 통합 앱입니다.

**Windows 10/11 x64:** `Windows-x64.zip`을 전부 풀고 `DesktopCharacter.exe` 실행. Python 설치는 필요 없습니다. `_internal` 폴더를 함께 유지하세요.

macOS 앱은 ad-hoc 서명만 했으며 Developer ID 서명·공증을 하지 않았습니다. Windows EXE는 인증서 서명이 없습니다. 운영체제에서 출처 확인 경고가 나타날 수 있습니다. SHA256SUMS.txt로 파일의 다운로드 무결성을 확인할 수 있습니다.
