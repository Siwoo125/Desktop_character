# 정지 이미지로 AI 모션 만들기

macOS와 Windows의 **캐릭터 생성…**에서 사용할 수 있습니다. 개인 API 키를 등록하며 앱 제작자의 API를 공유하지 않습니다.

## 사용 순서

1. **기본 정지 자세 → 이미지 선택…**에서 몸 전체가 보이는 투명 PNG 한 장을 고릅니다.
2. 상단의 **API 추가 · 검증…**을 엽니다. 서비스를 선택하고 이름·모델 ID·개인 API 키를 입력합니다. **API 키 발급 페이지**는 해당 서비스의 공식 페이지를 엽니다.
3. **검증**으로 연결과 모델 조회를 확인한 뒤 **추가**를 누릅니다. 저장한 API를 수정했다면 다시 검증하고 **변경 저장**을 누르세요. 같은 서비스의 API도 여러 개 등록할 수 있고 **삭제**로 설정과 저장한 키를 지울 수 있습니다.
4. 생성 화면에서 **이미지 API**를 선택하고 **전체 모션 만들기**를 누릅니다. 정지 자세 오른쪽의 **이 정지 자세로 전체 만들기**도 같은 기능입니다.
5. 결과를 미리보기로 확인하세요. 원하는 동작이 아니면 그 행의 **이 모션만 다시 만들기**를 누릅니다. 이름을 정하고 **저장하고 사용**을 누르면 새 캐릭터 한 마리를 추가합니다.

전체 생성은 시선·달리기·오른쪽 걷기·왼쪽 걷기·대기·점프/하강·커서 잡기·구르기 **8종**을 한 장씩 만듭니다. 기본값은 이미 등록한 모션을 건너뜁니다. 전부 바꾸려면 **기존 모션도 다시 만들기**를 선택하세요. 정지 이미지는 교체하지 않습니다.

점프는 현재 선택한 **두 줄 도약/하강** 또는 **연속 8자세** 순서를 따릅니다. 예시는 현재 선택한 강아지/보노보노 세트의 해당 동작입니다. 강아지의 왼쪽 걷기는 오른쪽 걷기 예시를 반전해 보냅니다.

## 서비스별 역할

| 서비스 | 용도 | 처리 방식 |
| --- | --- | --- |
| OpenAI | 시트 생성 | Image Edits API에 정지 이미지와 모션 예시를 함께 전달하고 투명 PNG 요청 |
| Google Gemini | 시트 생성 | 두 이미지를 함께 전달하고 단색 배경 요청 → 앱에서 배경을 투명하게 변환 |
| Anthropic Claude | 선택 설명 보조 | 두 이미지를 분석해 모션 설명 작성 → 선택한 OpenAI/Gemini API가 실제 시트 생성 |

Claude만으로 시트를 만들 수는 없습니다. Claude를 등록한 경우 **Claude 보조 (선택)**에서 고르고, 이미지 API도 별도로 선택하세요. 기본값은 보조를 사용하지 않습니다. Claude 보조를 켜면 두 서비스에 같은 정지 이미지와 해당 모션 예시를 전송합니다.

모델 ID는 수정할 수 있습니다. 채팅 전용 OpenAI 모델이나 이미지 출력을 지원하지 않는 Gemini 모델은 사용할 수 없습니다. 검증은 모델 정보 조회이며, 유료 이미지 생성을 시험하지 않습니다. **모델 조회 성공이 생성 권한·계정 인증·API 잔액·정확한 8프레임 출력을 보장하지는 않습니다.** 실제 생성 시 제공자가 거절하면 이유에 맞는 안내를 표시합니다.

공식 문서: [OpenAI Image API](https://developers.openai.com/api/docs/guides/image-generation), [Gemini 이미지 생성](https://ai.google.dev/gemini-api/docs/generate-content/image-generation), [Claude Vision](https://platform.claude.com/docs/en/build-with-claude/vision).

## 요금·취소·실패

개인 계정의 API 요금과 한도가 적용됩니다. 웹 서비스 구독과 API 사용 요금은 별도일 수 있습니다. 전체 생성은 최대 이미지 요청 8회이며, Claude 보조를 켜면 분석 요청도 최대 8회 추가됩니다. 기존 모션을 건너뛰면 요청 수가 줄어듭니다.

실패한 요청을 자동 반복하거나 다른 계정으로 자동 전환하지 않습니다. 완료한 모션은 남기고, 실패한 모션의 기존 이미지는 보존합니다. **생성 중단**은 진행 중 요청 취소를 시도하고 다음 요청을 멈춥니다. 서버가 이미 처리한 요청의 과금까지 취소되지는 않을 수 있습니다.

결과는 실제 이미지 형식·크기·투명 배경·격자별 빈 프레임 조건을 검사한 뒤에만 적용합니다. Gemini는 각 칸의 가장자리와 연결된 배경색만 제거해 몸 안의 같은 색은 보존합니다. 잘못된 배경이나 빈 칸이 남으면 결과를 적용하지 않습니다. AI가 정확한 자세와 캐릭터 일관성을 항상 지키지는 않으므로 재생 미리보기로 확인하세요. 특히 **커서 잡기·구르기의 손 접점**은 프레임별로 다시 맞추는 것이 좋습니다.

## 저장과 전송

- API 키: macOS 로그인 키체인 / Windows 자격 증명 관리자. 평문 파일로 저장하는 대체 방식은 없습니다.
- API 이름·모델·검증 시각·선택 정보: macOS `~/Library/Application Support/DesktopFriends/ai-connections.json`, Windows `%LOCALAPPDATA%\DesktopFriends\ai-connections.json`.
- 키는 캐릭터 JSON, PNG, 예시 내보내기, 로그, 저장소에 기록하지 않습니다. 키는 이 PC에서만 사용하며 캐릭터 폴더를 다른 PC에 옮겨도 함께 이동하지 않습니다.
- 검증은 선택한 서비스에 모델 정보만 조회합니다. 생성할 때는 정지 이미지와 해당 모션 예시를 함께 전송합니다. 전송 이미지는 최대 변 1536픽셀 PNG로 정리하며 원본 파일은 수정하지 않습니다.
- 요청은 각 제공자의 고정된 공식 HTTPS 주소로 전송하며 인증 정보가 다른 주소로 전달되지 않도록 리다이렉트를 따르지 않습니다. 제공자의 응답·정책 필터·잔액은 해당 계정의 조건을 따릅니다.
- 생성 결과는 임시 폴더에 두고, **저장하고 사용**을 누르면 사용자 캐릭터 보관함으로 복사합니다. 화면을 닫거나 저장을 마치면 임시 파일을 정리합니다.

## 개발 검사

`--creator-window-check`를 포함한 macOS 검사와 Windows의 `--widget-check`는 가짜 HTTP 응답과 메모리 자격 증명 저장소로 AI 요청·저장·UI를 검사합니다. 실제 API를 호출하거나 실제 키체인/자격 증명 관리자에 테스트 키를 저장하지 않습니다. 라이브 서비스의 결과 품질·잔액·계정별 권한 확인은 본인의 키를 등록한 후 수행해야 합니다.
