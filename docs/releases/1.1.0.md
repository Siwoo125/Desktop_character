# DesktopCharacter 1.1.0 · 설치하고 바로 만나는 바탕화면 친구

강아지·보노보노·내 캐릭터가 바탕화면에서 걷고 뛰는 macOS / Windows 앱입니다.

## 설치 후 바로 실행

- **macOS 13 이상 · Apple Silicon / Intel:** `DesktopCharacter-1.1.0-macOS-Universal-Installer.dmg`을 열고 **바탕화면 친구 설치.app → 설치하고 실행**을 누르세요. 사용자 응용 프로그램 폴더에 설치한 뒤 바로 실행합니다.
- **Windows 10/11 · x64:** `DesktopCharacter-1.1.0-Windows-x64-Setup.exe`로 설치하고, 마지막 화면의 실행 체크를 켠 채 **마침**을 누르세요.
- 처음 실행하면 강아지 한 마리가 나타납니다. 업데이트는 기존 앱의 **모두 종료** 후 진행하세요. 캐릭터·개인 API 설정은 유지합니다.
- 설치 없는 ZIP도 두 운영체제 모두 제공합니다. 전체 압축 해제 후 앱을 직접 실행하세요. Python·Swift 설치는 필요 없습니다.

**다운로드만으로는 실행되지 않습니다. 설치 파일을 한 번 열어야 합니다.** 관리자 권한이나 로그인 시 자동 실행 설정은 사용하지 않습니다.

## 정지 이미지로 AI 모션 만들기

- **캐릭터 생성 → 정지 PNG 선택 → API 추가 · 검증 → 전체 모션 만들기**
- 걷기·달리기·점프 등 8개 모션 생성, 동작별 재생성·취소 지원
- 개인 OpenAI / Gemini 이미지 API 사용, Claude는 선택적인 모션 설명 보조
- 생성마다 정지 이미지와 해당 모션 예시를 함께 전송. 키는 macOS 키체인 / Windows 자격 증명 관리자에 저장
- 생성에는 개인 API 요금이 적용됩니다. 검증은 모델 조회이며 생성 권한·잔액·품질을 보장하지 않습니다.
